# Overview

React Native Essentials is a beginner-first collection of guides, recipes, and example apps that teach React Native fundamentals through short tutorials and hands-on projects.

Why this repo exists

- Lower the barrier to entry for new React Native developers.
- Provide compact, example-driven tutorials that can be completed in 30–120 minutes.
- Offer reproducible example apps (Expo-first) so learners can run code quickly.

Learning paths

- Starter: Hello World (Expo)
- Beginner: To-Do app with local storage
- Intermediate: Weather app with networking and caching
- Advanced: Offline-first notes app with sync

See docs/setup.md to get started on your machine.
