# Setup — Expo-first (recommended)

This guide shows how to set up a development environment using Expo, which simplifies getting started with React Native.

Prerequisites

- Node.js (LTS) installed
- npm or yarn

Install Expo CLI

npm install -g expo-cli

Create and run the hello-world example

cd examples/hello-world
npm install
expo start

Open the QR code in Expo Go on your iOS/Android device or run on an emulator.

Notes

- We recommend Expo for most learning material because it avoids native build complexity.
- For learning native module bridging or integrating custom native code, see the advanced modules section in docs/ (coming soon).
