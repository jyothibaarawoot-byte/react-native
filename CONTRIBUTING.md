Thank you for contributing to React Native Essentials!

How to contribute

- Reporting issues: Use the issue templates provided under .github/ISSUE_TEMPLATE.
- Proposing docs/tutorials: Add a markdown file under docs/ or examples/ and open a pull request with a clear description and learning objective.
- Code style: Please run Prettier and ESLint (if included) before submitting a PR.
- Branching: Create a topic branch named `feature/<short-name>` or `docs/<short-name>`.

Code of conduct

By participating, you agree to follow the project's Code of Conduct in CODE_OF_CONDUCT.md.

Maintainers will review PRs and usually reply within a few days. If your PR touches an example, include steps to run it locally in the PR description.
