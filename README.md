# React Native Essentials

React native essentials — a beginner-first curriculum, guides, and examples to learn React Native by building real apps.

## What you'll learn

- How to set up a React Native development environment (Expo-first)
- Core primitives (View, Text, Image, TextInput)
- Styling and layout with Flexbox
- Navigation with React Navigation
- State management and networking
- Native capabilities, animations, testing, performance, and deployment

## Quick start (Expo recommended)

1. Install Expo CLI (if you don't have it):

   npm install -g expo-cli

2. Run the hello-world example:

   cd examples/hello-world
   npm install
   expo start

3. Open the project in Expo Go on your device or an emulator.

See docs/setup.md for more details.

## Repository structure

- docs/ — learning guides and curriculum
- examples/ — working example apps (Expo-first)
- recipes/ — quick patterns and how-tos
- exercises/ — hands-on tasks with solutions
