# Hello World (Expo)

This example demonstrates how to run a simple Expo app included in this repository.

Steps to run

1. Install dependencies:
   npm install

2. Start Expo:
   expo start

3. Open the app in Expo Go or an emulator.

What to explore

- App entrypoint (App.js)
- Basic components: View, Text, StyleSheet

You can copy this folder to a new Expo project or run it directly.
